# LegalEase: AI-Powered Legal Document Generator

## Team
- Team Leader: R. Vidhya kumaran
- Team Members: R. Tharun, M. Suyambu lingam

## Project Overview
LegalEase is an AI-assisted web application concept for generating structured legal-document drafts from user-provided information. The system guides users through a document type, collects relevant details, produces a draft using a configurable AI service, and allows the user to review, edit, and export the result.

## Important Notice
LegalEase is an academic prototype and is not a substitute for a qualified lawyer. Generated text must be reviewed by an appropriate legal professional before being used for a real legal matter.

## Suggested Document Types
- Rental / Lease Agreement draft
- Non-Disclosure Agreement draft
- Affidavit draft
- Simple authorization / consent letter
- Employment-related letter
- Legal notice draft

## Main Features
1. User-friendly document-type selection
2. Dynamic input form
3. AI-assisted draft generation
4. Review and edit workflow
5. Validation and required-field checks
6. Export-ready document
7. Generation history / status tracking concept
8. Privacy-conscious handling of user data

## Suggested Technology Stack
- Frontend: HTML, CSS, JavaScript / React
- Backend: Node.js / Python
- AI layer: approved LLM API
- Database: MySQL / PostgreSQL
- Authentication: secure session/JWT-based authentication
- Document export: PDF/DOCX generation library

## Run Concept
1. Configure the backend and AI provider securely.
2. Start the application server.
3. Select a document type.
4. Enter the required facts.
5. Generate the draft.
6. Review and edit the generated content.
7. Export only after verification.

## Academic Scope
The project demonstrates AI-assisted document drafting, UI validation, software engineering workflow, and responsible use of generative AI. It does not claim to determine legal rights, provide legal advice, or replace professional review.
